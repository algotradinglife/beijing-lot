关键洞察

1. N=4 跨多个 Kelly 系数都是最优族

除了 Sharpe 单一指标（N=2 在低 Kelly 下胜出），N=4 主导 CAGR、Calmar、终值。说明 4 关组合是 niche q ≈ 1.4 数据下的"最优分散数"。

2. Kelly 系数比 N 选择更敏感

对 N=4：Kelly 从 1/4 → 1/16 → DD 从 −81% → −37%（砍半），但 Calmar 从 5.81 → 7.15（升）。"少下注但更聪明"完胜 Kelly-optimal。

3. N=3 在所有 Kelly 上 Sharpe 都低

N=3 CAGR 高（最优 361%）但 Sharpe 在 0.05–0.30 之间。说明 3 关在 niche q ≈ 1.4 下变量太大，回报靠少数巨爆驱动。

4. N=5 在低 Kelly 下崩溃

N=5 Kelly=1/16 实际亏损（CAGR −2%）。原因：低 Kelly 下 stake 太小，过不了 2 元最低门槛 → 太多 combo 被剔除 → 命中数据不足。N≥5 不可行。
