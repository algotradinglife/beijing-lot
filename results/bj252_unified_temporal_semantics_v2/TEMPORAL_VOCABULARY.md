# Temporal vocabulary

- `historical_proxy`: `initial`, `10h`, `1h` are separate aggregate source-relative summaries, never a universal issue timestamp or row-level panel.
- `strict_forward`: an explicit UTC observation clock evaluated against the currently stored schedule reference. It is not reschedule-as-of authority.
- issue cutoff: earliest issue kickoff minus a declared lead; per-fixture and per-cell support is recorded.
- segment fallback: Asia/Shanghai local kickoff-date segment; cutoff is that segment's earliest kickoff minus the same lead.
- no model, ROI, ticket, or profitability claim is made.
