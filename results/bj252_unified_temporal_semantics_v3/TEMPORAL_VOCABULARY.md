# Temporal vocabulary

- `historical_proxy`: `initial`, `10h`, `1h` are separate horizon × market × field-role summaries from exact source lane `beidan_xlsm_workbook`, whose receipt requires exact `main`/`wal`/`shm` keys, never a universal issue timestamp or row-level panel.
- `poll_start_forward`: the local merged collector poll-start clock evaluated against the current schedule reference. It is not received-at, commit-at, per-cell lineage, or reschedule-as-of authority.
- collector issue/fixture identity: a URL-expect-derived synthetic bucket used only for this descriptive temporal profile. It is not canonical physical fixture or issue truth; #251 must resolve cross-issue aliases before #253 integration.
- storage-present SP cell: a physically non-null SQLite value before numeric parsing.
- model-valid SP cell: a parseable, finite decimal SP strictly greater than 1.0.
- issue-bucket cutoff: earliest kickoff in the collector URL-expect bucket minus a declared lead; per-row and per-cell support is recorded.
- segment fallback: Asia/Shanghai local kickoff-date segment; cutoff is that segment's earliest kickoff minus the same lead.
- no model, ROI, ticket, or profitability claim is made.
