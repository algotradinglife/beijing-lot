# #252 decision input (candidate)

This package profiles collector URL-expect bucket/cell coverage and poll-start age across 1/6/12/24h common bucket cutoffs and a deterministic local-date segment fallback. The collector-derived `issue_code` and `fixture_id` are not canonical physical fixture identity: cross-issue aliases must be resolved by #251 before #253 treats these rows as issue truth. It does **not** select a final lead or crawler cadence. Historical proxy is stratified by horizon, market and field role rather than pooled into an M×3 denominator.

Timezone convention: Asia/Shanghai scheduled kickoff values are explicitly localized then converted to UTC. The collector timestamp is poll-start, not data-received time; merged rows do not retain upstream per-cell lineage. Without schedule history these curves are descriptive against the current schedule reference. Missing snapshots, incomplete storage and invalid SP values are separate drop causes.

Internal checksums establish package integrity, not external authenticity after arbitrary re-signing. Each declared poll/proxy source lane is cross-bound to its exact SQLite main/WAL/SHM receipt-key set; the receipt proves only that those bytes were stable across this build interval. The frozen Parquet contains derived presence/validity counts rather than raw SP cell values, so downstream users cannot promote it to independently authenticated raw-value evidence.
