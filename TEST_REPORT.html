6. 测试驱动的核心结论（实测交叉验证）

策略数学已被测试链证实：

  • backtest::test_kelly_zero_when_no_edge — 验证 EV ≤ 0 时 Kelly = 0（防赌博损失）
  • combo_optimizer::test_break_even_per_leg — 验证 7 关 break-even q = 1.064
  • sweep::test_settlement_pays_out_correctly — 验证 ∏SP × 0.65 收益公式
  • sweep::test_weekly_cap_enforced — 验证 25% 周仓上限不会被突破
  • combo_optimizer::test_split_for_tax_under_threshold — 验证拆票后单注奖金 < 9999
  • drawdown::test_profitlock_skim — 验证 ProfitLock 资金分流逻辑
  • niche_corr::test_dynamic_top3_no_lookahead — 验证动量策略无 forward-looking bias
  • phase5a::test_pnl_log_cumulative_increases — 验证 PnL 累计追踪正确
