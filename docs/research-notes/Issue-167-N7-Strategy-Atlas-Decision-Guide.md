# Issue #167 — N7 策略图谱决策者解读

PI synthesis timestamp: **2026-08-04 12:50 Asia/Shanghai**

主经济口径：**税前投资回报率（ROI）**。税后 ROI 只作为敏感性参考。

范围：历史纸面研究；不构成购买、下注、生产或策略推广授权。

## 五分钟执行摘要

这轮研究把一张七场串关票拆成两个可以分别优化的环节：先由**选场器**从同一期
比赛中挑出七场，再由**票分配器**决定有限资金要买七场所有可能赛果中的哪些票。
七场每场三种赛果，一共有 `3^7 = 2,187` 张不同票；把 2,187 张全部买一遍称为
**全覆盖**。

决策者只需要记住五点：

1. **目前最可信的进步来自选场，但选场仍未打平。** 当前完整期、较宽样本的最好
   全覆盖基线是税前 ROI **−9.47%**。它比无门槛对照的 −15.77% 好，但仍是负值。
2. **票分配方法不能脱离选场器单独排名。** 同一种“不重复抽票”方法在一种选场器
   上优于重复抽票，在另一种选场器上反而更差。因此没有“永远应该重复”或“永远
   不应重复”的全局结论。
3. **两个正收益点是研究甜点区，不是已确认优势。** “概率×预测赔率权重、集中购买
   前 192 张票”的 +20.37% 高度依赖少数期；“模型概率、每票最多一份、购买 512 张”
   的 +8.14% 分布更宽，但置信区间仍跨过零。
4. **100 个随机种子只能减少抽样运气，不能增加足球历史。** 三种子时看起来为正的
   “概率×预测赔率权重、不重复购买 64 张票”方案，在 100 种子聚合后变成 −13.28%。这说明随机波动被压稳了，
   但期次、年份和大奖集中度仍然存在。
5. **#170 已证明“好选场 + 好分配”不能默认相加。** 两个甜点分配器移到最好选场器
   后分别降到 −13.37% 和 −16.66%。因此 #134 应先改善全覆盖选场基线，不能先把
   分配层的历史正点计作增量。

一句话决策：**保留 −9.47% 的完整期全覆盖选场器作为当前起点，用基本面和真正的
决策链继续改善选场；两个分配甜点只保留为后续诊断，不进入主继承面板。**

## 一张图理解整个系统

```text
同一期全部比赛
      │
      ▼
选场器 selector
挑出一组七场比赛，即一个 N7 identity
      │
      ├──────────────► FULL：2,187 张全部购买，隔离选场质量
      │
      ▼
票分配器 allocator
按概率或价值权重，从 2,187 张中分配 M 张 ¥2 票
      │
      ▼
税前 ROI + 相对同组选场 FULL 的 lift
      │
      ▼
bootstrap / LOYO / ex-largest / HHI
检查结果是否只是随机种子、某一期、某一年或少数大奖造成
```

读任何结果时都按这个顺序问：

1. 七场是谁选的？
2. 买了多少张票，允许不允许重复？
3. 绝对税前 ROI 是多少？
4. 相对同一个选场器的全覆盖基线提升多少个百分点？
5. 支持期数和集中度是否足以承受删掉最大一期、最大年份和重采样检查？

−42.54pp。

## 最好选场器名称逐字段解码

控制名称：

`S2_ESP290_GM300_MARKET_WF_CAL_MIN_LOWP20_COLD_FIRST_K1`

| 字段 | 含义 | 精确执行规则 |
|---|---|---|
| `S2` | 第二类完整期选场器 | 以一期全部比赛为池，用低概率赛果找锚点，再补足七场；不是模型版本号 |
| `ESP290` | companion 的单场期望 SP 下限 2.90 | 除锚点外，其余候选场次必须满足 `E_SP >= 2.90` |
| `GM300` | 七场期望 SP 几何平均下限 3.00 | 七场组成后必须满足 `GM_E_SP >= 3.00` |
| `MARKET_WF_CAL_MIN` | 最小概率来源 | 对每场三个赛果，取市场 walk-forward 校准概率中的最小值 |
| `LOWP20` | 冷门锚点门槛 | 至少有一个赛果的上述概率 `<= 0.20`，该场可作为锚点 |
| `COLD_FIRST` | 锚点排序 | 先按最小概率升序，再按 `E_SP` 降序，最后用场次序号和 ID 稳定打破平手 |
| `K1` | 每期只保留第一组七场身份 | 若没有完整合格七场，则该期明确 `NO_BET`，不从结果可用性补选 |

两个容易误解的细节：

- `E_SP = Σ_c p_c × predicted_SP_c`，是三个赛果的概率加权 SP，不是三个 SP 的
  算术平均。
- 低概率锚点本身不强制通过 `ESP290` 单场门槛；其余六场必须通过。最终七场整体仍
  必须通过 `GM300`。这保留了“挑出最可能排除冷门的场次”和“用高期望 SP 场次
  补足组合”两个不同角色。

## 术语表一：比赛与组合结构

| 术语 | 清晰定义 | 决策意义 |
|---|---|---|
| `N7` | 七场串成一张票，七场都对才中奖 | N 固定为 7，不能把其他 N 的结果直接迁移 |
| `issue` / 期 | 北单同一销售期中的完整比赛池 | 研究单位必须保持一期完整，避免 segment 改变问题 |
| `leg` / 腿 | N7 中的一场比赛 | 每腿有 `3/1/0` 三个赛果代码 |
| 赛果代码 | `3`、`1`、`0` 分别表示让球主胜、平、主负 | 一张票是七个代码组成的序列 |
| `selector` / 选场器 | 从一期比赛池中确定哪七场进入组合 | 它决定 FULL 基线，是当前瓶颈层 |
| `identity` / 组合身份 | 已冻结的七场比赛集合及其稳定 ID | 同一身份下才能公平比较 allocator |
| `K` / top-K | 每期保留多少个合格七场身份 | `K1` 是每期最多一个；不是每期下注张数 |
| `NO_BET` | 冻结规则下该期没有合格身份 | 必须保留为零下注，不能事后补候选 |
| `allocator` / 票分配器 | 在一个七场身份的 2,187 张可能票之间分配资金 | 改变资金覆盖，不应和选场贡献混算 |
| `FULL` / 全覆盖 | `3^7=2,187` 张不同票各买一份 | 每个身份下注 ¥4,374，是隔离选场质量的控制组 |
| `sleeve` / 策略仓 | 固定选场器上的一个特定权重、分配机制和 M 配置 | 是可继承的研究组件，不等于已确认策略 |

## 术语表二：概率、SP 与排序

| 术语 | 清晰定义 | 决策意义 |
|---|---|---|
| `SP` | 北单赛果的结算赔率/返还倍数口径 | SP 越高不代表概率越高 |
| `E_SP` | 一场三个赛果的 `概率 × 预测SP` 之和 | 用于衡量全包该场的预期 SP 质量 |
| `GM_E_SP` | N 场 `E_SP` 的几何平均 | 防止一场很高的值掩盖多场低质量 companion |
| `p_min` | 一场三个赛果中最小的预测概率 | 用于寻找最不可能发生的赛果/冷门锚点 |
| `MODEL_P_CAL` | 模型概率经过 walk-forward 校准后的三赛果权重 | 强调模型概率，不直接包含 SP 价值 |
| `MARKET_WF_CAL` | 欧赔市场隐含概率经过 walk-forward 校准后的权重 | 是当前历史研究中较可靠的市场概率底座 |
| `Q_WEIGHT` | 对每个赛果使用 `校准概率 × 预测 SP` 后再归一化的权重 | 同时偏向概率与赔率价值，但不是完整决策链 |
| `COLD_FIRST` | 先选最小概率更低的锚点 | 对应“优先排除最不可能爆冷赛果”的原始设想 |
| `VALUE_FIRST` | 先选 `E_SP` 更高的锚点 | 更偏重价值，可能牺牲冷门排除强度 |

## 术语表三：票分配机制

| 术语 | 清晰定义 | 决策意义 |
|---|---|---|
| `M` | 每个七场 identity 实际购买的 ¥2 票数 | 资金为 `M × ¥2`；M 不是最大单期资金上限 |
| `WR` | weighted sampling with replacement，按权重有放回抽取 | 同一张票可被抽到多次，重复份额都下注，但不增加赛果覆盖 |
| `WOR` | weighted sampling without replacement，按权重无放回抽取 | 每张票最多出现一次；M 增大后会被迫纳入较低权重票 |
| `duplicate stake` | 同一票被重复购买，每份均是独立 ¥2 税务/结算单位 | 提高高权重票的资金暴露，不提高 unique coverage |
| `cap1/cap2/...` | 单张票最多允许 1/2/... 份 | 在集中概率与扩大覆盖之间设上限 |
| `residual` | 先按权重计算理想票数，再用最大余数法分配整数票 | 确定性近似概率比例，不依赖 seed |
| `TOP_MASS` | 按联合权重从高到低，确定性取前 M 张或分配前部质量 | 直接集中到权重最大的票，不等同随机 WOR |
| `seed` | 随机抽样的确定性随机数起点 | 同一 seed 可复现；多 seed 衡量抽样噪声 |

为什么 WOR 与 WR 会反转：当高权重集中在少数真正有价值的票时，WR 的重复下注可能
合理；当重复只是浪费覆盖时，WOR 更好。随着 M 增加，WOR 还会逐步吸收低权重尾部。
结论取决于 selector、权重来源和 M 的组合。

## 术语表四：收益与稳健性

| 术语 | 清晰定义 | 如何解读 |
|---|---|---|
| 税前 `ROI` | `(税前返还 − stake) / stake` | #167 和后续研究的主经济口径 |
| 税后 `ROI` | 每张中奖票按冻结税制扣税后的净收益率 | 仅作敏感性；不能替换税前主结论 |
| `lift` | 候选 ROI 减去同 selector、同 support 的 FULL ROI | 用百分点 pp 表示，隔离 allocator 的增量 |
| `support` | 某策略实际可选择且有可信结算的期/身份集合 | support 不同，绝对 ROI 不能直接因果比较 |
| `matched support` | 两个策略限制到完全相同的期和可比较身份 | 用于做 lift 或迁移归因 |
| `bootstrap` | 以完整 issue 为块重复有放回抽样，再计算 ROI 分布 | 保留同一期内相关性，衡量历史期次不确定性 |
| 95% `CI` | bootstrap 分布的 2.5% 到 97.5% 区间 | 下界仍小于 0，不能称为稳定正 Edge |
| `LOYO` | leave-one-year-out，每次删掉一个完整年份后重算 | 检查结果是否由某一年主导 |
| `ex-largest` | 删除净贡献最大的单一期或单一年份后重算 ROI | 正值若随最大赢家消失，说明收益集中 |
| `HHI` | 各期 gross 返还占比平方后求和 | 越高表示返还越集中在少数期；不是收益指标 |
| `top issue share` | 最大返还期占全部 gross 的比例 | 比 HHI 更直观地显示单期依赖 |
| `drawdown` | 累计税前盈亏从历史峰值到后续谷值的最大下降 | #167 是金额口径；百分比和风险调整指标由 #176 补充 |
| `longest miss streak` | 连续没有中奖返还的最长 issue 数 | 描述资金和心理承受压力 |
| `Pareto frontier` | 在 ROI、回撤、集中度等维度上没有被另一方案全面压过的集合 | 用于缩小研究范围，不代表全部可投产 |
| `Edge` | 经独立、稳定、可执行证据支持的正期望优势 | 单个历史正 ROI 点不自动成为 Edge |

## 决策视角重述

### 1. 选场是当前瓶颈

`BEST_FULL` 的 −9.47% 是当前最有用的起点，因为它：

- 按完整 issue 选择，不依赖 segment；
- 有 163 个可结算期，而不是几十期的小样本尖峰；
- 使用 FULL 枚举，不让票分配机制替选场器背书。

它仍为负，所以 #134 的目标不是证明旧 sleeve，而是让同一 FULL 对照在基本面或真正
决策链加入后向零靠近。负 overlay 不得降低或替换这条基线。

### 2. WOR 与 WR 没有全局优劣

在 `NO_GATE/K4 + Q_WEIGHT` 上，M64 的 WOR 为 −13.28%，WR 为 −19.48%；在严格
S2 + `MODEL_P_CAL` 上，M32 的 WR 为 −11.26%，WOR 为 −24.69%。机制排序反转
说明 allocator 必须与 selector、权重和 M 一起冻结和报告。

### 3. 两个甜点区承担不同研究角色

- `Q_WEIGHT + TOP_MASS/M192` 的 +20.37% 是高回报压力测试。其绝对 bootstrap
  95% 区间为 `[−37.86%, +95.04%]`，去掉最大正贡献 issue 后为 −3.28%，gross
  HHI 为 0.0833。它告诉我们右尾可能存在，但证据高度集中。
- `MODEL_P_CAL + cap1/M512` 的 +8.14% 分布更宽。绝对区间为
  `[−9.78%, +27.23%]`，去最大 issue 后仍为 +4.40%，HHI 为 0.0127；但去最大
  年份后为 −0.21%，所以仍不能升级为绝对 Edge。

### 4. 多 seed 解决的是抽样运气

三 seed 的离散结果不能区分真实票分配信号与幸运随机序列。扩展到 100 seed 后，
Q-WOR/M64 从历史三种子约 +10.27% 回落到 −13.28%。这提高了对 allocator 均值的
认识，但 bootstrap、LOYO、ex-largest 和 HHI 仍需要另外回答“足球历史是否稳定”。

### 5. #170 的控制结论是 `SELECTION_ONLY`

#170 把两个甜点 sleeve 原样迁移到 `BEST_FULL`，没有重新调参：

- FULL：−9.09%；
- Q-M192：−13.37%，相对 FULL −4.27pp；
- MODEL-M512：−16.66%，相对 FULL −7.57pp。

因此选场改善和分配改善没有在控制 support 上相加。`MODEL_SOURCE × MODEL-M512`
的 +14.09% 说明 selector-context 交互真实存在，却不能迁移成 BEST_FULL 的收益。

## 对 #134 的执行约束

#134 只有在 [#175](https://github.com/algotradinglife/beijing-lot/issues/175) 本解读和
[#176](https://github.com/algotradinglife/beijing-lot/issues/176) 风险调整指标完成后才应恢复。
恢复时必须遵守：

1. 主面板只继承 `BEST_FULL × FULL_ENUMERATED`，native-support 税前基线 −9.47%；
2. 同期冻结市场-only、基本面-only、真正决策链-only、基本面+决策链四个 FULL arm；
3. `Q_WEIGHT` 只是 q 代理，不得冒充既有 v3.3.3/v4.2 决策链；
4. 每个 overlay 先报告绝对税前 ROI，再报告相对同 support 市场 FULL 的 lift；
5. Q-M192 与 MODEL-M512 只能放在 FULL 主结果之后做诊断；
6. 若得到正值，必须检查 bootstrap、LOYO、ex-largest、HHI、百分比回撤及独立 EV；
7. 若得到负值，详细说明哪一层没有提升，同时保留 −9.47% incumbent，不以
   `NO_CANDIDATE` 草率结束。
