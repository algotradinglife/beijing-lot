# Issue #119：候选标准敏感性与上游信号扩展

> [!summary]
> 放松 #106 的“已晋级 strata”要求后，候选池确实出现；但大部分单选和全部
> 全覆盖 arm 仍为负。少量正 ROI 集中于 2019，且高阈值 arm 的样本很小。
> 这不是策略晋级或购买建议；正值行正等待独立只读复验。

GitHub：[Issue #119 — BJ-HIST-CANDIDATE-SENSITIVITY-001](https://github.com/algotradinglife/beijing-lot/issues/119)
代码审查：[Draft PR #120](https://github.com/algotradinglife/beijing-lot/pull/120)

## 问题与边界

#106 的终局结论是 `NO_PROMOTION`，因为没有任何 strata 达到当时的晋级标准。
#107 的全样本结论是 `ALL_NO_BET_UPSTREAM_NO_SIGNAL`，#108 因而没有运行。
本研究不重写这些结论；它只问：**严格候选规则本身是否把可检验的候选全部排除？**

所有比较均为历史纸面研究。概率和候选来自 #106 Gate A 的 timing-proxy
历史快照，不是严格赛前的生产输入；赛果和最终 SP 仅在 Gate B 读取。没有购买、
生产筛选或策略推广授权。

## 冻结设计与可复现性

Gate A 先冻结 `8 × 7 × 2,659 = 148,904` 个 pool/variant/arm 前沿行，随后才执行
统一结算。Gate A 有 94,958 个候选场次分配。完整分母包含 344 期和每个显式
`NO_BET` 行，而不是只报告有票的 pool。

| 维度 | 冻结规则 | 经济假设 |
| --- | --- | --- |
| 严格对照 | `STRICT_106_PROMOTED`，0 候选 | 复现 #106 的终局边界，而不是把它改写成负收益。 |
| q 下界 | `q_lb ≥ 0.90 / 1.00 / 1.10` | 较高保守值可能压缩赔率不确定性，代价是样本骤减。 |
| 校准概率 | `p_cal ≥ 0.20` 或 `0.35` | 排除极低概率代码，检验概率质量而不是只检验高赔率。 |
| 支持与持久性 | 始终 `support ≥ 500`、至少 3 个年份 | 保持可审计的样本基础；本轮**没有**再放松这两项。 |
| 熵 | `entropy ≤ 1.08` | 候选分布更尖锐时，单选的错误尾部可能更小。 |
| q 稳定度 | `q_lb / q_hat ≥ 0.85` | 用 q 的下界/点估计比率作保守不确定性代理。该阈值在本样本没有额外排除。 |
| 集中度 | 单一代码最多占 pool 候选 80% | 防止“所有候选都是同一结果码”的伪分散。 |
| 决策链特征 | `FUNDAMENTAL_DECISION_CHAIN_UNAVAILABLE` | 审计源中没有可用的同周期基本面/决策链字段，显式保留 `DATA_UNAVAILABLE` 对照。 |
| 票型 | 单选 N4、单选 N7、动态 N4/N7；三选全覆盖相同腿集；无投注对照 | 分开检验场次选择与覆盖成本，不能把覆盖率当作单选命中率。 |

每场只取通过规则的最高 `q_lb` 代码；pool 内按 `q_lb`、`match_idx`、`match_id`
排序。完整的参数定义、逐场分配、年度/结果码分布、原因普查和缺失/集中度表在：

- `results/bj119_gate_a_preoutcome_v1r1`，manifest
  `bc2684f6e38dac76af6943e0fbd134613dbb3d2af9d80160a6505354e5311983`；
- `results/bj119_gate_b_outcome_settlement_v1r3`，manifest
  `62f29ac6035e397b2d6dc7ea0d366983901cf1cbf1320649da3e6ae8fd4f4af9`。

v1r3 只修正 Gate B 的报告语义：时序诊断按 `year / first_kickoff_ts /
segment_index / pool_id` 排列，并把 Gate-A `NO_BET` 与 canonical outcome
不可用分别计数。共有 179 / 1,232 个 robustness rows 的回撤和/或最长连败改变
（26 个 `ALL`、153 个 `LOYO`，`YEAR`/`FOLD` 为 0）；Gate A、逐行结算、
stake、gross、tax、net 和 ROI 均未改变。

2019；这不是跨年稳定证据。

## 结算口径

所有 56 行比较都使用同一 canonical trusted outcome/final-SP 输入；每个命中票的
毛额为 `¥2 × 0.65 × ∏ final_SP`，税按同一 variant/arm/issue 的总毛额在
`¥10,000` 门槛处汇总计算。`portfolio_settlement.csv` 保留逐行票、赌注、命中、
SP、税和净额。没有后验调参、删期或只报告正值行。

## 年度、fold 与留一年外解释

`q≥1.10` 的两个单选正值全部位于 `OOS_2019`；2020–2025 都是 0 个
eligible period。因此其“LOYO 2019”行没有样本，不能被描述为 LOYO 稳健。
`q≥1.00/N4` 的正值也几乎全来自 2019：2019 ROI +54.51%，其余年份合计
只 4 个 period、净 -¥8。相反，较宽但更有样本量的 q≥0.90,p≥0.35/N4 在
2019–2025 总体 -19.81%，只有 2021 与 2024 出现孤立正年。

这说明差异的主要来源不是得到跨年重复支持的候选质量，而是：

1. q 阈值同时改变候选密度和年度构成；
2. N7 单选的乘积赔率对一张高 payout 票极其敏感；
3. 低熵、q 稳定度本轮没有带来独立改善（稳定度 arm 与 q≥0.90,p≥0.20 完全相同）；
4. 覆盖票提高“覆盖命中”却扩大组合成本，不能替代概率/赔率优势；
5. 基本面决策链特征和可用 league 层级在绑定输入中缺失，不能把未知信息当优势。

## 结论与下一步

**研究结论：候选标准是一个真正的瓶颈，但当前放松规则没有给出可推广的稳定策略。**
严格 #106 对照的零候选并不等于所有放松标准都不可能产生票；然而正 ROI 仍由
2019 的极少数 observation 主导。当前状态为 `FROZEN_RESULTS_PENDING_EV_IF_POSITIVE`，
不是 `PROMOTION`。

严格独立 EV 需要复核固定远端 HEAD、两个 manifest 和 payload、完整 56-arm
分母、无泄漏重放、canonical final-SP、0.65 一次应用、逐 issue 税汇总，以及
所有正值行的年度/fold/LOYO 与 exclude-best 诊断。只有该复验通过并且 PI 作出
独立解释，才可以讨论后续研究；本页不提议购买或生产使用。

本轮一个明确限制是：为了不在看到收益后扩大网格，`support` 和 `persistence`
没有进一步放松，GM-SP、市场 dispersion、预测 SP 不确定度也只被记录为可审计
源字段而没有形成额外 post-outcome 变体。若 PI 认为这些维度值得研究，必须由
**新的、在未查看目标期赛果前冻结的独立实验** 承担，不能回填进本 #119 结算。
