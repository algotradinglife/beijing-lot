## 2. 判断（我的解读）

1. **这是个结构性负 EV 的游戏**：35% 抽水压在一个半有效的彩池上。**选腿没问题**——是玩法结构（串关 + 早决策 + 吃满漂移）把一手 +EV 的牌打成了 −26%~−50%。
2. **「找 edge」的方向基本穷尽且为负**（O2-O5）。继续找选腿/错价 edge 是低期望的。
3. **剩下的价值全在结构与成本**：
   - 减少结构损失：**降 N**（少复利漂移）、**临近开赛决策 / 漂移 haircut**（O6 的模型已量化）。
   - **降低成本门槛**：返点/税务拆票不创造 edge，但能把盈亏平衡线往下挪——这是唯一可能把「约打平」变「转正」的杠杆，且没算过。
   - **纪律性空仓**：多数时候无 edge，正式把「不下注」做成一级动作。
4. **诚实的可能性**：即便压榨所有结构杠杆，结果也可能只是「约打平到微负」。**能否转正大概率取决于成本结构（返点）**；否则理性结论是 **don't bet / 设预算上限当娱乐**，外加一个隔离的**登月仓**博大奖。

## 3. 下一步计划（按价值排序，标注可测性）

### Tier 1 — 结构性杠杆
- **A1 降 N walk-forward（N=2/3/4）** — ✅ 现在能测。replay 支持任意 N，在 live 数据上做干净 out-of-time 比较，验证「N3 样本内 +19.7%」是否 OOS 站得住。**性价比最高的可测项。**
- **A2 漂移 haircut / QHC（MVP）** — ⏳ 要等数据。drift_model + 保守分位 + QHC arm 已建好、无泄露、每周累积；轨迹只 7.5 周，需攒到 QHC≥数十命中或 8-12 周再裁决（已预注册）。
- **A3 成本/返点/税务敏感性** — ✅ 现在能测。纯会计+敏感性：返点率多高能让策略转正？税务拆票对高SP的真实削减？**可能一锤定音改变可行性判断。** 设计稿 cost_rebate_tax_edge.md。

### Tier 2 — 风险/纪律
- **B1 no-bet / 可交易窗口** — ✅ 现在能测。回测「选择性空仓 vs 每期都押」的资金曲线/回撤。设计稿 no_bet_trading_window.md。
- B2 集中度/分散度 — 部分已上线（autoplan 集中度门），可再调。

### Tier 3 — 长尾 / 不同目标

## 4. 推进方式与纪律（已沉淀）

- **每张卡**：TDD（红-绿-重构）→ 本地 commit（不 push）→ 交 reviewer 审本地 commit → **审核通过才 push** → 一轮复盘（评估是否调整后续卡）→ 下一张。
- **forward arm 的模型/参数只用 pre-forward 数据训练/冻结**（防前瞻泄露，P3 踩过）。
- **任何北单 vs 欧赔比较先过校准 sanity 检查**（让球/直盘错配会造假 +EV）。
- **backlog 卡建完即 block**（防 auto-decomposer 自动拆开开工）。
- 实盘 **auto 当前运行 S9 低风险**；haircut/q降权/bucket/QHC 都默认关或纸面，不动真钱直到 forward 给 verdict。

## 5. 我的推荐（接下来两步，都现在能测）

1. **先做 A3（成本/返点/税务敏感性）**：它可能一锤定音——若返点足够高，「约打平」的策略本就转正，那整个结论翻转。纯会计，现有数据即可。
2. **再做 A1（降 N walk-forward）**：直接验证最强的结构性信号（降 N）在干净 out-of-time 上站不站得住。

两者都按 §4 的卡片+审核+复盘流程推。其余 Tier 2/3 视结果再排。

## 6. 风险与局限

- **轨迹数据薄（7.5 周）**：漂移/QHC/降N 的 OOS 裁决都受此限，需时间。
- **市场有效 + 35% 抽水**：结构地板可能就是翻不过去——要对「最终理性结论=不押/娱乐化」保持开放。
- **小样本**：所有 forward/walk-forward 结论都需预注册判据 + 足量样本，避免重蹈 N=5「甜区」那种抽样假象。
