本页验收当前 package 接口，并读取独立冻结的历史模拟对照。win、draw、lose 分别是北单让胜、让平、让负，不能传入普通胜平负概率。取消单选；三选优先（最大与最小概率差不超过10个百分点，浮点边界容差1e-15），否则第三赛果为让平且概率严格大于20%时提供两种互补双选，其余普通双选。此10个百分点沿用现有研究规则，不是本轮历史收益拟合所得。

输入三个有限数值标量，各在[0,1]，合计容差1e-9，不自动归一化。输出无名称列表，元素为明确赛果名称的字符向量。排名同概率按win、draw、lose确定；三选输出固定顺序。函数只提供允许方向，不保证两方向被买入，也不决定组结构、复用或预算。

加载块从当前目录向上寻找 `packages/beidan/DESCRIPTION`，因此从仓库根目录、`quarto/` 或 package 目录逐块执行都指向同一个开发包；当前目录必须位于本仓库内。`rprojroot` 是项目已有依赖，运行时不安装。

## 排名：覆盖优先与均衡优先

下面是固定合成概率夹具，不是实盘建议，也没有学习或校准历史参数。七场均使用北单让球胜平负的含义；不混入普通欧赔胜平负。原始输入直接在本页声明。决策时点显式固定，北京时间2026-09-26 20:00，接口内转换UTC；这是夹具身份，不是原始市场可用性证明。

```{r}
decision_at <- lubridate::ymd_hms("2026-09-26 20:00:00", tz="Asia/Shanghai")
cutoff <- list(issue_id="26098",
               cutoff_utc=lubridate::with_tz(decision_at, "UTC"))
chain_matches <- tibble::tribble(
  ~fixture_id, ~win, ~draw, ~lose,
  "26098:001", .40, .30, .30,

  "26098:003", .38, .31, .31,
  "26098:004", .45, .22, .33,

  "26098:007", .55, .15, .30
)
chain_selections <- beidan::prepare_outcome_selections(chain_matches)
```

## 购买：额度、去重与实际覆盖

主例总预算512元、每组最多256元；每注2元。同样的七场可以用不同互补掩码构成不同候选，但同一物理票只购买一次。后选组跳过已买票，继续向排名更深处购买新票；若新票耗尽则实际花费减少。复用/重叠本例明确不设限制，不是生产默认。主方案实际结构统一，不同结构应分开评估。

```{r}

knitr::kable(evaluation$group_selection)
```

只显示购买账本前12行，完整账本在evaluation$purchases。此夹具未提供赛前SP，预计收益必须显示不可计算，而不是补造收益。该例各票都包含相同七场，因此不同物理票互斥，购买联合覆盖率可独立按各票概率求和验证；跨不同场次组不能一般这样求和。
