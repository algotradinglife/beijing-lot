## 0. 问题与机制

把每场押**市场最热门**（最低 SP）选项。两条相互对抗的力：

- **抽水摊薄（有利）**：北单返还率 0.65 = 每**票**一次性抽 35%，**不分腿**。所以每腿盈亏平衡所需的 `v = p×SP` 随 N 下降：`v* = 1.538^(1/N)`（N=4 需 1.114，N=7 仅 1.063）。
- **热门偏差（有利）**：实测热门腿 **realized v = p×SP = 1.082 > 1**（命中率 0.418 × 命中均结算 SP 2.59）。散户高估冷门、低估热门，使热门略微被低估。且热门是「往上漂」的（band 图 <3.5 +33%），按结算 SP 拿钱 = **顺风漂移**（我们现行押冷门是逆风）。

⇒ 若腿**独立**，`EV = 0.65 × v^N` 随 N 升、约 **N=6 翻正**。

- **正相关（不利）**：同晚热门可能一起爆冷，`P(全中) < Πp`，真实远低于独立上界。

## 1. 结果

| N | 每腿盈亏平衡 v* | 独立上界 EV | **模拟真实 ROI** | 相关拖累 |
|---|---|---|---|---|
| 2 | 1.240 | −23.9% | −33.1% | 0.88 |
| 3 | 1.154 | −17.6% | −15.8% | 1.02 |
| 4 | 1.114 | −10.9% | −19.9% | 0.90 |
| **5** | 1.090 | −3.5% | **+4.8%** | 1.09 |
| 6 | 1.074 | +4.4% | −4.0% | 0.92 |
| **7** | 1.063 | **+13.0%** | **−62.5%** | **0.33** |
| 8 | 1.055 | +22.2% | −49.6% | 0.41 |
| 10 | 1.044 | +43.1% | **−100.0%** | 0.00 |

- 独立上界=`0.65·v^N`；模拟=同期次热门随机 N 串、按真实赛果用结算 winning_sp 结算（3000 样本/N，捕捉真实相关性）；相关拖累=模拟/上界（<1 ⇒ 正相关吃收益）。

## 2. 结论

1. **机制成立**：抽水每票一次 + 热门 v=1.082>1 → 独立上界确实随 N 升、约 N=6 翻正。**「低 SP 下提高 N」方向正确**。
2. **但正相关在 N≥7 处砸碎它**：相关拖累从 N≤5 的 ~0.9 骤降到 N≥7 的 0.33→0；N=7 真实 −62.5%、N=10 −100%（同晚热门一起爆冷，全中概率塌缩）。**上界翻正之处，恰是相关性变致命之处——高 N 处相关性赢。**
3. **甜区在 N≈5**：上界与真实都贴近盈亏平衡，N=5 模拟 **+4.8%**、相关拖累 1.09。这是本项目研究至今**第一个真实越过 0 的组合**。
4. **真正的杠杆不是「更高 N」，是「不相关的热门」**：若能挑出彼此不会一起爆冷的热门腿，独立上界成立、高 N 才赢。⇒ 把 `joint_q_correlation_edge` / `scenario_portfolio_construction` 从「q 死路」翻身为**潜在活路**，但要用在**热门**上，而非现行的冷门 mid-SP。

## 3. 局限（勿据此投真钱）

- **样本薄**：仅 16 期；N=5 的 +4.8% 可能是噪声，N=4 −20% / N=6 −4% 说明波动大。需 OOS 验证 → 已加 **`FAV5` forward arm**（`src/sp_drift/forward.py::favorite_arm_row`，每周累积，平注、不进 GATE-FT）。
- **税务封顶未建模**：热门串 N 高时 `2.59⁷≈990`，叠 stake 易撞 1 万单票封顶 → 20% 税/拆票，会再吃高 N 收益（见 [[cost_rebate_tax_edge]]）。
- **用「每场最热门」全集，未做选择**：选 v 更高、相关更低的热门子集应更好——正是 §2.4 的方向。
- 用结算 winning_sp（已含热门的有利漂移）；决策端能否锁定这些热门是落地问题。

## 4. 下一步

- `FAV5` arm 已上线，逐周累积 OOS。
- 若 OOS 站得住，按 §2.4 做「**不相关热门子集**」的组合构造（joint_q on favorites），并把税务封顶纳入 sizing。
