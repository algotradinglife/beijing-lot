# 固定选组的回款与资金复用对照

本轮属于 #459 / PR #462 诊断扩展。冻结784期JOINT输入，保持每期已选组及各组票数上限；
预算1024元，2元票，票级回款0.65一次。赛前估算价格来自市场概率，实际SP仅用于结算。

四臂主比较：原JOINT、预计单票回款至少256元、单场最多承载768元且同方向最多512元、两者结合。
另公开128/512元回款和更严格512/384元暴露格子作为敏感性，全部报告，不按目标期标签选赢家。
这不是严格未见验证：旧概率和可用时点证据只能作为历史诊断。不能按收益曲线挑门槛后称前瞻验证。

过滤票允许由同组选中场次的更低排名组合补足，组票数不超过原配额。资金暴露按2元票金额累加；
同场七串票的全部2元均算承载风险，不除以7。不同组共享场次时汇总。全局按票概率下降决定购买优先级。
无约束时必须逐组精确复现原概率前缀及整期投入回款。新臂不新增组，也不把原闲置预算补满。

实现复用共享Cutoff边界、已验证枚举表、先冻结后结算及输入/代码绑定。测试覆盖重复ID、现金、
同方向风险、替补票、结果变更不影响选票、原方案重放。输出覆盖全期/回撤/后段净收益ROI回撤命中、
模型覆盖、现金、过滤与新增回款贡献；重叠组覆盖不得简单相加称为期命中概率。

在原供给与配额范围回答收益过滤和复用限制是否有效，不将固定组负面结果外推为所有重新选组策略无效。

## 784期验收结论

原JOINT投入706950元，净收益53188.68元，ROI7.5237%，最大回撤35125.71元，命中345期。
256元过滤同投入净收益45987.15元，ROI6.5050%，回撤35772.46元，命中351期。
768/512资金限制投入592996元，净收益−31149.03元，ROI−5.2528%，回撤59787.27元；
两者结合净收益−31554.58元，ROI−5.3212%，回撤63848.63元。均无资金不足停投。

不采用这三个主变种。256过滤提高中奖票条件回款，却减少同一期多组中奖；资金限制换出了有价值的票，
替补票为负收益，不能解释为仅减少投入。128元轻过滤提高净收益3494.86元，但只有14期改善、
30期变差，最大单期改善2484.28元；回撤段反而稍差。仅作有限敏感性证据，不视为解决回撤的升级。
