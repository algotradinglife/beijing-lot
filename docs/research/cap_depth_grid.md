# 压一场／压两场的37组复用参数对照

[可执行QMD85](../../quarto/85_cap_depth_grid.qmd)给出全部148策略、7,104个逐期结果和17幅图。
范围为同一批已暴露的48期100402–100607；预算每期1,024元，本金100,000元。
纯基线、TOP2概率排序、不重叠前缀、有限候选池；无专家、比分保护、额外预算或重训。
U为每场最大复用次数，P为任意两组最多共同场数。
固定U1/P0与U∈{2,3,4,6,8,16}×P∈{1,…,6}，两种深度、BASE和75%单选替换。
BASE／替换保持同组、同单选位置、同投入及现金；不同深度可能选不同组。

## 结论

**同预算下，当前48期的压两场整体明显强于压一场。**
不替换时37组参数中压两场净收益全部更高，34组回撤更低；
75%替换后35组净收益更高、19组回撤更低。压一场仅在U4/P4、U4/P5的替换方案上反超。
不同参数可能得到相同投注，这些计数不是独立试验次数。

|深度／规则|本样本最高收益参数|净收益（元）|预算ROI|最大回撤（元）|预算使用率|剔除最大盈利期后的净收益（元）|
|---|---|---:|---:|---:|---:|---:|
|压一场／不替换|U3/P5|2,352.09|4.79%|10,839.53|97.40%|-5,326.93|
|压一场／75%替换|U4/P5|10,824.13|22.02%|7,895.53|98.70%|-570.01|
|压两场／不替换|U6/P5|30,678.31|62.42%|8,470.38|97.14%|22,212.24|
|压两场／75%替换|U16/P6|41,508.04|84.45%|9,216.00|100.00%|16,795.88|

这四行分别是同组别事后最高值，不能把不同参数的差异全部归因于替换效果。
压一场不替换只有3/37组盈利，替换后17/37组盈利；压两场对应36/37和34/37。
压一场的75%替换在22组提高收益，压两场只有11组提高收益。
因此可以同时成立：替换更常帮助压一场，但压两场的最终收益仍普遍更高。

压一场U4/P5的同组BASE收益226.04元，替换增加10,598.10元；
配对剔除增益最大的一期后，剩余替换增益仍为2,922.87元。
但压一场的全部37组替换方案，剔除各自最大盈利期后总净收益均为负。
它的改善值得保留为回顾候选，尚不能解释为稳定盈利。

压两场不替换的U2/P4是较低回撤对照：净收益15,536.90元、预算ROI31.61%、
最大回撤3,747.41元，预算使用率70.31%，剔除最大盈利期后仍盈利10,648.40元。
U6/P5盈利30,678.31元、回撤8,470.38元；U16/P6＋75%替换盈利41,508.04元、回撤9,216元。
后者的替换增益剔除最大增益期后为−8,037.23元，不能只比较总收益。
这些是不同风险水平的历史候选，不自动提升为默认策略。

## 成本、约束和因果边界

压一场每组128元、最多8组；压两场每组64元、最多16组。
严格约束下无法扩组就持有现金：U1/P0压一场使用74.48%预算，压两场仅44.79%。
收益率同时提供预算口径和实际投注口径，回撤包含初始本金和未使用现金。
候选池大小512，并未证明全局最多可投注组数；不能将剩余现金全部解释成理论无解。
复用上限、两注重叠上限的放宽不保证贪心选组结果单调改善，亦不保证实际组数单调。

75%规则沿用既有实现：首次出现不变；后续出现且本次为单选、原p1≤75%时选原第二方向；
再次出现仍选第二、不交替；双选始终不变。原概率和市场映射不改，最终SP仅结算。
完整命中基本票的返奖为2元×0.65×七场SP乘积，0.65仅乘一次。

全部计划在本轮读取结算前冻结，但这些2010年期次此前已经暴露。
不把同一队列的参数选择包装为训练外或跨年验证，#419继续被#421阻塞。
