# 合理让球线细化到0.5球

入口quarto/244_half_handicap_line.qmd，配置config/half_handicap_line.json。
同一744期68,826条保存的原市场比分矩阵，分别最小化|W-L|（整数/半球步长）和
|W-L|/(W+L)（半球步长）。后者仅改变寻线标准，实际命中仍包含让平在分母，
结算仍是北单原整数线。未重估模型、未搜索最优阈值、未重整零让球欧赔矩阵。
195期归档矩阵未纳入。2010/2015覆盖不完整，不能称全集或未见数据。

直接差新增26,647条，实际方向命中46.24%；条件差新增31,256条，命中45.79%。
所有新增信号都是0.5球差。原整数基线逐场完整复现，无并列合理线。

结论：半球刻度有分型价值，可以区分弱分歧与更强分歧。新增0.5球信号并不是高命中
单选；低于50%也不表示方向错误，因为让平是第三类。保留下来的1球差命中更高，
伴随覆盖显著收缩与模型预期提升，不可声称变换刻度改善了相同场次的预测。
条件差1球格63.60%高于直接差60.76%，两格样本不同，不能据此宣布条件定义更优。
本轮没有新策略ROI或7串1实验，不能从命中率推断盈利。
