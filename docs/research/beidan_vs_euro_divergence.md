## 0. 动机与方法

「北单（软彩池）相对 sharp 欧赔系统性错价」是唯一与「选腿已 +EV」不冲突、理论上可能有真 edge 的方向。用历史 38k 场测：

```
p_euro(s) = (1/eu_s) / Σ(1/eu_o)          # 比例法去水
D = winning_sp × p_euro(winner)            # 北单 gross 赔率 / 欧赔公允赔率（D>1=北单多赔）
投影单腿 q ≈ D × 0.65                       # >1 ⇒ 翻过 35% 抽水、+EV
```

## 1. 陷阱：北单是「让球」，欧赔是「直盘」——被校准检查逮住

**全样本（含 39% 让球盘）**：

| euro_p 桶 | realized hit | 桶中点 | | D | 投影q |
|---|---|---|---|---|---|
| <0.2 | **0.335** | 0.1 | ✗偏离 | 0.470 | 0.305 |
| 0.2-0.35 | 0.294 | 0.275 | | 0.966 | 0.628 |
| 0.35-0.5 | 0.408 | 0.425 | | 1.032 | 0.671 |
| ≥0.5 | **0.369** | 0.6 | ✗偏离 | **1.606** | **1.044 ←看似+EV** |

> **校准破裂**：sharp 欧赔的概率竟然预测不了赛果（realized hit ~平）。原因：北单 `result_code/winning_sp` 是**让球后**结果，而 `avg_eu_*` 是**直盘 1X2** 欧赔——两者口径错配。这把「大热门 D=1.61、+EV」**凭空造了出来**。**幸亏加了校准 sanity 检查，否则会得出假的 +EV 结论。**

## 2. 干净比较：只看 `handicap_line=0`（无让球，北单=直盘）

23,059 场（line=0 占 61%；非0让球占 39%）：

| euro_p 桶 | realized hit | 桶中点 | | D | 投影q |
|---|---|---|---|---|---|
| <0.2 | 0.139 | 0.1 | ✓ | 1.003 | 0.652 |
| 0.2-0.35 | 0.281 | 0.275 | ✓ | 1.051 | 0.683 |
| 0.35-0.5 | 0.422 | 0.425 | ✓ | 1.004 | 0.652 |
| ≥0.5 | 0.541 | 0.6 | ✓ | 1.014 | 0.659 |

> **欧赔校准良好**（realized ≈ 桶中点）→ 欧赔可当真值。**北单 D 全桶 ≈ 1.0**（1.00~1.05），投影 q≈0.66 = 纯抽水，**全部远低于盈亏平衡**。

## 3. 结论（负结果，重要）

1. **北单相对 sharp 欧赔定价高效**：直盘（line=0）上 D≈1.0 across 所有概率档——**没有可利用的错价偏差**。北单 SP ≈ 欧赔公允赔率。
2. **「大热门 +EV」是让球错配假象**：混入让球盘、拿让球结果比直盘欧赔造出来的；校准检查暴露之，line=0 上信号消失。
3. **「北单 vs 欧赔偏离」这条 edge 候选关闭**（至少直盘上；让球盘需先把欧赔按 handicap_line 调成让球概率才能比，但直盘已无 edge，让球盘有的可能性低）。
4. 与全局一致：[[q-persistence]] q 无时间结构、[[pnl_attribution]] 选腿+EV但亏在结构、本研究北单≈欧赔——**市场有效，亏损是结构性（抽水×漂移），不是选腿/错价能解决的。**
5. 修正之前：[[high_n_favorite_parlay]] 的 live favorite v≈1.12 在此大样本干净比较下回到 ≈1.0——那点「热门价值」多半是小样本噪声 + 让球/热门定义差异。

## 4. 局限

- 直盘欧赔 vs 让球北单不可直接比；本研究的有效结论限于 `handicap_line=0` 子集（23k，仍大样本）。
- D 用 winning_sp（赢家）算，winner-conditioned；但 line=0 上 D≈1.0 的结论对此稳健（各档一致、校准良好），不依赖幸存者假设方向。
- 让球盘（39%）的北单 vs 欧赔需 handicap-adjust（用 1X2 supremacy + 让球线建模）才能测——但鉴于直盘无 edge，优先级低（YAGNI）。

## 5. 方法论收获

**任何「北单 vs 欧赔」比较都必须先过校准 sanity 检查**（realized hit vs 去水欧赔概率）。让球/直盘口径错配会凭空造出 +EV 假象——这是本研究最重要的可复用纪律。
