# 新版市场概率底座：纯市场7串1 U3/U6

按用户最新裁决，完全去除战力概率。比较原市场RAW与`market-balance-draw-1.0.0-diagnostic`的CAL。
原有共识筛选、分歧配额、零让球Top2分歧排除、50%单选门槛都不在本轮；不做任何分歧/随机替换或比分保护。
这与此前混合战力/市场的U3/U6结构不同，本报告只做相同纯市场策略下RAW/CAL配对比较。

## 方法与接口

`src/market_foundation_n7.py::market_foundation_n7`仅接受身份、让球、q_W/D/L。
若传入战力或赛果列则拒绝；复用通用引擎时，内部p/q列均为同一套市场概率，并非使用战力。
`src/fundamentals_n7_single.py::n7_single_plan`增加显式`max_pair_overlap`参数，原默认值2保持现有研究策略；本轮传入5。
先按Top2累计概率排序分配不重叠7场组，随后既有MILP按组Top2概率乘积扩组。
组内按Top1概率选两场单选，其余五场买Top2。U3/U6单场最多复用3/6次，任何两组最多重叠5场。
这不是联合优化单选位置和所有组的全局最优解，不加入历史训练或隐含阈值。
每期预算1024元、每注2元、32注/组即64元；最多16组，余额现金保留。

`scripts/replay_market_foundation_n7.py`先检查已有新底座的模型收据、源哈希、版本与逐期预测，
再并行冻结100期×4策略共400套计划，最后读取已有权威R/SQLite胜平负结算导出。
使用既有`settle_n7_single`结算，0.65仅在中奖票上乘一次；没有复制SP结算公式。

```
python -m scripts.replay_market_foundation_n7 --foundation data/derived/fundamentals_417/market-balance-draw-v1 --output data/derived/fundamentals_417/market-foundation-n7-v1
quarto render quarto/124_market_foundation_n7.qmd --execute-dir . --execute --no-cache
```

新输出目录必须不存在。QMD复用`strategy_equity_curves`，展示100期明细、ROI、资金/回撤曲线；初始资金100000元。
全部100期都有下注，序列现金流假设一期全部结算后进入下一期；历史标签代理和逐场时点限制不变，historical_admission=False。
不能将该诊断称为真实同时可买到全部盘口的前瞻回测。#419/#421不因这次收益变好而关闭。
