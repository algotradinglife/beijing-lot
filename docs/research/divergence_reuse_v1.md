# 分歧驱动复用 v1

## 研究问题

在保持概率底座、SP 估计、1024 元预算和结算口径不变时，能否用让球线分歧与 Top2 清晰度控制场次复用，并只在第三赛果增量预期回报覆盖资金分散成本时纳入第三赛果。

## 实现

`r/divergence_reuse_allocate.R` 提供两个纯函数：`divergence_reuse_features()` 从赛前特征生成 HIGH/MEDIUM/LOW 可信度；`divergence_reuse_allocate()` 在冻结候选池上按边际命中收益/资金选择组合，执行逐场复用上限和显式回报门槛。函数不读取结算、不拟合历史、不修改概率。

## 证据边界

分歧是无标签的赛前诊断变量，不能被解释为第三赛果发生率预测器。研究应同时报告净收益、ROI、回撤、命中期数、现金留存和复用集中度；若第三赛果门槛提高只减少投入而没有改善单位资金回报，则不纳入下一版。
