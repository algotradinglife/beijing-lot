## 0. 背景与边界

用户思路转向：要求 **N≥6/7 高串、「确定的就压、不确定的就包」**，看能做到什么程度，并问 xlsx（历史战绩+赔率变化）能否预测腿。决定 = **两条并行**：
- **Track A（本文）**：现有数据上量化「**纯市场、无 leg-edge** 下高N覆盖的诚实下限」。
- **Track B（待全量 xlsx）**：用历史战绩+赔率变化预测每腿，测能否赢过收盘池 → 真 edge。

**主仓低N纪律不变（A1/A3）；高N覆盖是隔离的登月仓（C2），真钱需用户确认。**

### 概率口径：本 Track A 用「北单 SP-implied」而非欧赔去水（重要）

每腿的「无 edge 基线概率」用**北单 gross 决策 SP 去水**得（$p_o=\frac{1/sp_o}{\sum 1/sp_o}$，因 $\sum 1/sp_o\approx1$ 故 $p_o sp_o\approx1$）。这是**北单池自身的隐含概率**，正是「相对池无 edge」的定义，最保守。

**为什么不用任务 body 写的欧赔去水 p**：欧赔是直盘 1X2，北单是**让球**胜平负——非 line=0 时两者口径错配（O5）。reviewer 的 probe 实测：naive 用欧赔 p + 北单 SP 会算出荒谬 EV（N=7 单选 EV≈21417），正是 O5 的让球错配。**sanity 检查**：仅在 `line=0`（直盘可比，791 腿）上，北单 SP-implied p 与欧赔去水 p 平均逐结果 |Δ|=**0.075**（一致，证 O5「北单≈欧赔」），故 SP-implied 可靠且无错配风险。Track B 才会用独立 p_hat 替换这个基线。

## 1. 覆盖的 EV 恒等式（覆盖不改 EV）

覆盖一条腿 = 买该腿覆盖结果的笛卡尔积张票。可证（`coverage.py`，已 TDD）：

$$\frac{\text{EV}}{\text{预算}} = RR \cdot \prod_i \frac{\sum_{o\in C_i} p_o\,sp_o}{|C_i|}$$

市场公平时 $p_o sp_o\approx1$，故 **EV/预算 ≈ RR×drift^N，与覆盖程度、票数无关**。覆盖只把**命中率↔奖金形状**对调，不改 EV。唯一能抬 EV 的是 $\prod$选腿 > 1（真 leg-edge，Track B）。

## 2. 无 edge 下限：漂移让高N远比「−35%」更惨

`drift_gm = 0.758`（决策在 19.6h-out，realized 腿 winning_sp/decision_sp 几何均值）。纯市场单选串 EV/元 = RR×drift^N：N=2 **37.4%**(亏63%)、N=4 21.5%、N=7 **9.3%**(亏91%)。**「−35%地板」只是 N=1**；漂移随 N 复利（0.758^7=0.14）。

## 3. 漂移其实是「用决策SP选腿」的诅咒——可以绕过（回答用户）

**关键事实：北单永远按结算 SP（开奖赔率）赔付，与你何时下注、下注时 SP 无关。** 所以决策时 SP 从来只是个**选腿输入**，不是你拿到的赔率。"drift"（决策SP→结算SP=0.758）本质是**用一个早而噪声大的 SP 去选腿**带来的赢家诅咒（低SP上漂、高SP下漂，你专挑会下漂的），是**选择偏差，不是赔付税**。

**推论（用户两个问法都成立）**：
1. **完全不看实时SP、只用外部因子（周边公司赔率变化、近期表现、历史战绩）选腿** → 不吃决策SP的诅咒。正确基准变成**结算池隐含概率**，盈亏平衡门槛下降。
2. **SP 只当 filter（剔掉太差/极端腿）、不追某区段、胜率优先** → 是合理的风险卫生（剔掉 O6 里漂移+方差最毒的极端longshot/高SP腿），但要分清下面这条。

**三种基准下，N=7 盈亏平衡所需每腿 sel = p_true/p_池**：

| 选腿基准 | drift | N=7 需 sel | N=4 | N=2 |
|---|---|---|---|---|
| 决策SP·远(19.6h) | 0.758 | 1.403 (+40%) | 1.469 | 1.636 |
| 决策SP·近开赛(3h) | 0.960 | 1.108 (+11%) | 1.160 | 1.292 |
| **外部因子·按结算SP**（用户思路） | **1.0** | **1.064 (+6.4%)** | 1.114 | 1.240 |

> **用户的直觉对**：脱钩决策SP、以结算池为基准，把 N=7 的每腿 edge 门槛从 +40%（远期决策SP）压到 **+6.4%**。这是抽水被高N摊薄（$RR^{-1/N}$）+ 零漂移的合力。

**但必须诚实的一条**：「胜率优先」**本身不创造 edge**。
- 盈亏平衡看的是 **p_true / p_池**（你的预测 vs 池的隐含），不是 raw 胜率。raw 胜率高=押热门=p高但 sp低，乘积 ≈ p_池 sp = 1 → 还是抽水地板。
- raw 胜率只对**登月目标（让串关存活，∏p）**有用：高 p 腿抬 P(命中)，但热门赔付低 → 奖金缩、EV 不变（正是 §5 覆盖前沿）。
- **唯一创造 EV 的，仍是「你的胜率估计 p_true 超过结算池隐含 p_池 ≥ +6.4%/腿」**——这就是 Track B，外部因子能否赢过收盘池。门槛被降到 +6.4%，但 O5 说池在收盘≈sharp，仍难；不过这是清晰、可测、且回报被N放大的目标。

## 4. 时机 × N（若仍用决策SP选腿）

把决策从 19.6h 挪到 3h：drift_gm 0.758→**0.960**，N=7 无edge EV 9.3%→**48.7%**（理想0漂移上限65%）。**漂移被升到N次方，临近决策对高N价值远大于低N。**（与 §3 一致：近开赛=用更准的SP选，逼近「按结算SP选」。）

![覆盖前沿](figures/high_n_coverage.png)

- **EV/预算 各档恒为 ~9%**（坐实 §1：覆盖不改 EV）。
- **cover-2 比 cover-3 更高效**：同样盖 n 条，cover-2 票更少（$2^n$ vs $3^n$）、奖金保留更多（盖7条中位奖 116 vs 17），因为丢掉的只是各腿最不可能的结果。代价是命中率增益小（22.7% vs 100%）。**若要包，优先 cover-2。**
- **P(≥100万)≈0、P(≥10万)≈0**：无 edge + 1000 预算，「少奋斗5-10年」级大奖概率实质为 0。
- **税务**：单压的稀有大奖（>9万）必破1万 → 必须拆票避20%税（A3 的 sizer 已有）。

## 6. 裁决：「能做到什么程度」

1. **无 leg-edge，高N覆盖是个差彩票**：EV −63%(N2)~−91%(N7)，覆盖/胜率优先只换命中率↔奖金、碰不到地板以上，P(大奖)≈0。光靠「包」或「押热门」不创造价值。
2. **用户的结构直觉成立**：高N摊薄一次性抽水 → 平衡所需每腿 edge 随N降；**脱钩决策SP、以结算池为基准（外部因子选腿）把 N=7 门槛降到每腿 +6.4%**；配近开赛/外部信号压住漂移诅咒。
3. **成败全在 Track B**：能否用 xlsx（战绩+赔率变化）拿到 p_true 超结算池 ≥+6.4%/腿。拿得到 → 高N+轻cover-2+按结算SP 是放大器；拿不到 → 隔离小预算纯彩票。
4. **若有 edge 后的构造器目标函数**：外部因子估 p_hat → 在 p_hat/p_池 最高（最有 edge）的腿单压、仅对维持串关存活的腿 **cover-2**（非无脑全包），SP 仅作 filter 剔极端腿，不追band。

## 7. 局限

- **漂移用 flat geomean**：真实漂移随 SP档/MTK 变（O6），flat 是一阶近似；高SP腿漂移更狠。
- **p = 北单 SP-implied**（无edge基线）；Track B 用独立 p_hat 时 sel≠1，§3 的门槛才有意义。
- **覆盖策略**：单压最确定、cover-2/cover-3 最不确定 n 条；真优化（按 p_hat/p_池 选单压腿）是 Track B 有 edge 后的问题。
- **MC 30万/档**：P(≥100万) 极尾仍噪声大，只能说「≈0」。
- 预算 1000 是示例；登月预算与封顶/拆票联合建模属 C2 正式启动范畴。
