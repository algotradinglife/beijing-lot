## 0. 问题

[[moonshot-high-n]] Track A 证明：高N覆盖不改 EV，登月要从「彩票」变「可行」，唯一杠杆是**每腿预测胜率超过收盘池 ≥+6.4%/腿**（drift-free 门槛）。Track B 在 19 万场（11.5 年）上检验这点：用**外部因子**（多家博彩开/收盘赔率、开→收盘线移、亚盘、排名）能否赢过博彩收盘共识？诚实先验（O5）：收盘线≈sharp，极难赢过。

## 1. 方法（codex 审核确认无泄露、口径公平）

- **P0 ETL**：header-driven、layout-validated 解析采集器 853 列 → 干净「每场」表。**后赛果列(比分/半全场/总进球)一律不入库**，仅 `result_code`(胜负→3/1/0) 作标签；`FEATURE_COLUMNS` 全部严格赛前。让球留空=line 0(直盘)。
- **P1 基准校准**：博彩**收盘共识**去水概率作 benchmark。在 line=0(113,078 场，直盘↔让球结果可比，守 O5)上校准良好：home/draw/away 最大缺口 0.019/0.019/0.028 ✓ → 「赢过收盘线」是良定义问题。
- **P2 walk-forward**：test 季 t∈2016-2025，**只用 season<t 训练**、预测 t（严格时间外推，codex 确认无泄露）。模型：benchmark(p_close) vs 多项 logistic vs HistGBM，特征=18 个赛前列（含 p_close、线移、亚盘、排名）。指标：OOS 多类 log-loss / Brier / 准确率 + CLV 偏离-lift。预注册裁决：模型 OOS 稳定超基准、且隐含每腿 edge≥+6.4% 才算有 edge。

## 2. 结果：模型 ≈ 收盘线，无经济意义的 edge

**汇总 OOS（2016-2025，~155k 预测）**：

| 模型 | OOS log-loss | Brier | 准确率 | Δlog-loss vs 基准 |
|---|---|---|---|---|
| **基准（收盘共识）** | 0.9937 | 0.5934 | 0.5114 | — |
| logistic（全特征） | 0.9934 | 0.5932 | 0.5119 | **+0.0003**（噪声级） |
| HistGBM（全特征） | 0.9941 | 0.5938 | 0.5105 | **−0.0004**（反而更差） |

逐季 gbm−基准在 −0.0013~+0.0018 之间来回，**无一致改进**。模型即便同时看到收盘价本身 + 线移 + 排名 + 亚盘，也**追平不了、更超不过收盘共识**。

**CLV 偏离-lift（gbm 对 home 偏离 vs realized，诚实记录一丝残余信号）**：

| 偏离桶 | n | 均偏离 | p_close | realized | 方向 |
|---|---|---|---|---|---|
| [−1,−0.10) | 248 | −0.160 | 0.496 | 0.415 | ✓ |
| [−0.10,−0.03) | 8114 | −0.045 | 0.381 | 0.381 | ✓ |
| [−0.03,+0.03) | 124042 | +0.003 | 0.414 | 0.417 | ✓ |
| [+0.03,+0.10) | 22337 | +0.045 | 0.557 | **0.575** | ✓ |
| [+0.10,+1] | 266 | +0.126 | 0.408 | **0.462** | ✓ |

模型与收盘价分歧时**方向上略对**（全桶 ✓，非纯噪声）：中等正偏离桶(2.2万场)realized 高于收盘 **+1.8%**，极端正偏离(266 场)+5.4%。但——**量级 ~1-2%（有效样本）、集中在极小尾部、净 log-loss≈0**，远低于高N所需 +6.4%/腿。

## 3. 裁决（预注册判据未满足）

1. **外部因子赢不过博彩收盘线**：OOS log-loss 改进 ≈0（logit +0.0003、gbm −0.0004），19 万场/11.5 年。**无可利用的选腿 edge。**
2. **一丝残余信号但不可用**：CLV 显示模型偏离方向略对，但 ~1-2%、稀疏尾部、净中性——**够不到 +6.4%/腿门槛**，串起来更不可能。
3. **登月仍是纯彩票**：Track A 的「无 edge 下限」成立——高N覆盖只塑形 P(命中)↔奖金、EV 恒为 −35%×漂移。**P3（接 北单 winning_sp 变现）moot**：没有 edge 可变现，且北单收盘 SP ≈ 博彩收盘（O5），更无空间。
4. **与全局一致**：在 19 万场大样本上再次坐实**市场有效**——[[beidan_vs_euro_divergence]] O5、[[sp-drift-study]]、[[n_walkforward]] A1、本研究，选腿/错价/预测 edge 全部关闭。**钱只能从结构（降N/时机/纪律）省，赚不到。**

## 4. 对登月仓的最终建议

既然无 leg-edge：高N登月**只能当 EV-agnostic 彩票**玩（隔离小预算、博 P(中大奖)、完全不指望转正）。若仍要做，按 Track A：近开赛决策（压漂移）+ 沿 Pareto 前沿按目标 P(命中) 选 cover-2 为主的覆盖 + SP 仅 filter 剔极端腿 + 拆票避税。**主仓维持低N纪律不变；真钱动作需用户确认。**

## 5. 局限

- benchmark 是博彩**收盘共识**；个别 sharp 单簿（Pinnacle 收盘）可能略强，但模型已含各簿收盘+线移仍未超出，故结论稳健。
- 让球盘(非 line=0)的 benchmark 用直盘共识近似（未做 supremacy 转换对齐北单让球线）——但 P2 在全样本上预测 result_code、特征含亚盘，结论（无 edge）对此不敏感；严谨的让球-line 对齐是未做的精细化，鉴于无 edge 优先级低（YAGNI）。
- 模型族限于 logistic / HistGBM 默认超参（walk-forward）；更大模型/更细特征工程理论上可榨，但收盘线效率 + 净 log-loss≈0 表明上限很低。
