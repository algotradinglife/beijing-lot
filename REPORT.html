1. 核心结论

一句话总结
方法学可行（Pinnacle 反推真实概率经实证校准良好），但北单历史数据有结构性缺失（销量比 + 输方 SP 不存档），导致核心 edge 假设（散户群体偏差）只能靠未来 6+ 个月的 live 数据验证。设计稿与 5 项实证分析已完成；任何投入应区分"探索期"与"已验证期"。
  • 1方法学可行：Pinnacle 1X2 校准误差 < 2pp、AH 校准 < 1.5pp、Skellam AH→1X2 重建偏差 ~1.1pp（与原书价 Brier 无统计差异）。
  • 2发现一个必修偏差：Skellam 在整数线上系统性低估让球后平局 (p1) 约 2.8pp（实际 27.5% vs 预测 24.8%）。每注 "1" 选项被低估 EV ~6.2%。
  • 3批次必须 N ≥ 50：Monte Carlo 显示 5% 真实 edge 下，N=50 → P5 ROI = −18%；N=10 → P5 ROI = −45%。北单一期只有 5–10 场 → 批次必须按周聚合。
  • 4EV 阈值 T = 0.05 默认（最小化最坏损失）；T = 0.10–0.15 适合长期增长。T ≥ 0.18 在高噪声下让 log-growth 转负。
  • 5仓位规则定型：1/4 Kelly + 三层上限（per-match 5% 资金 / pool 0.5% / batch 25%）。文献支撑（MacLean–Thorp–Ziemba 2010, Whelan 2025）。
  • 6Edge 仅一种站得住脚：散户群体 SP 偏好（draw aversion + popularity bias）vs 国际市场。v1 必须实证验证 — 否则项目无 edge 应停止。

2. 投注论 (Bet Thesis)

2.1 北单 SP 机制

  • 彩池模型（parimutuel）：奖金 = SP × 2 × 0.65
  • 返奖率 65%，房费 35%（远高于 Pinnacle 的 ~3%）
  • 不是和庄家对赌，而是和其他购彩者对赌

2.2 Edge 来源

结构性 +EV 假设：北单购彩者群体（中国散户）的投注分布偏离国际博彩市场（Pinnacle 等）的真实概率估计。

偏差假设方向信心来源
平局选项 SP 系统性偏高（散户回避平局）"1" +EV高Forrest & Simmons; Deschamps & Gergaud
主队/热门球队赢球 SP 偏低"3" 热门 −EV中Fischer 2022 (COVID 自然实验)
极端冷门 SP 偏低（FLB 残留）极冷门 −EV中Snyder 1978; Hausch–Ziemba–Rubinstein 1981
小盘比赛 SP 噪声大±10% 双向高直觉 + 中文行业分析
⚠ 关键论断
上述假设若不成立或不足以覆盖 35% 房费，策略无 edge。第一阶段必须用真实北单 SP 历史数据验证。

2.3 P_real（真实概率）来源 — Approach A 已验证

从国际博彩市场（Pinnacle）反推：

Pinnacle AH（让球数 + 赔率）+ Pinnacle O/U 2.5 → Skellam(λ_h, λ_a) 拟合 → 北单整数让球数下读取 p3/p1/p0

3.2 Pinnacle AH 校准

  • Margin: 2.34%
  • Always-back-away ROI: −0.006%（基本完美有效）
  • 仅 23.75% 比赛是整数让球线 → 76% 需要 AH→1X2 转换

3.3 Skellam AH→1X2 转换（EPL 2024-25 校准）

  • Mean abs prob error: 1.12%
  • Brier vs outcome: 0.583（与 Pinnacle 自家 1X2 统计无差）
  • 6/6 单元测试通过；conversion 在 8903 场上零失败

v1 双轨方案：

  1. h = 0 场次（56% 比赛）：直接用 Pinnacle 1X2（去 vig 后）。无校正需要。
  2. |h| = 1 场次（32% 比赛）：Skellam + 经验校正 p1 += 0.020; p3 -= 0.010; p0 -= 0.010
  3. |h| ≥ 2 场次（12% 比赛）：Skellam 原值（残差 < 0.5pp，无需校正）

3.6 Winner's Curse — EV 阈值 T 的设定

实际操作点 σ_p ≈ 0.03（含 Pinnacle 自身噪声 0.025 + 我们重建误差 0.011），edge_mean = +1%：

目标 A — 最小化批次最坏损失

T = 0.05，每周 N ≈ 50 候选。批次 P5 ROI ~ −18%。
v1 默认采用此目标（用户原诉求）。

目标 B — 最大化长期 log-growth

T = 0.10–0.15，每周 N ≈ 25 候选。批次 P5 ROI ~ −25%（更糟）但平均增长更高。

4.1 仓位计算公式

edge_i      = p_i × SP_i × 0.65 − 1
f_kelly_i   = edge_i / (SP_i × 0.65 − 1)
f_actual_i  = 0.25 × f_kelly_i
stake_i     = min(
                f_actual_i × bankroll,
                0.05 × bankroll,         # per-match 上限
                0.005 × pool_i           # pool 自影响上限
              )

5. 数据风险与应对（实测后已确定）

✓ 好消息：500.com 全量可爬
~2,115 期（自 2007-05），共 ~170k 场。单脚本 ~80 LOC，~70 分钟跑完。备份源 cp.zgzcw.com。无 JS、无验证码、无观察到的限流。
⚠ 坏消息（影响回测设计）
  1. 历史只保留中奖选项 SP。输的两个选项 SP 已被擦除。
  2. 销量分布（每选项投注百分比）历史不留档。这是验证群体偏差最关键的信号。
  3. 平均欧赔（1X2 主流博彩平均赔率）历史完整保留 — 关键回退方案。
  4. 赛前实时 3-SP + 销量比是有的，但需 Live Collector 持续抓取。

5.1 应对方案：双轨数据策略

轨道 1：Live Collector（立即开始）

常驻爬虫 poll 北单投注页，5–15 分钟一次，捕获完整 3-SP + 销量比 + 让球数。

6–12 个月后才有真正可用于策略验证的数据集。
工作量：~2 人天。

轨道 2：Limited Backtest with Proxies

用 170k 历史 + 平均欧赔代理 SP，构建近似回测。验证模型对平均欧赔的预测准确性。

不能验证群体偏差量级。
工作量：1 人周。

8. 重要警告

警告 1：北单不是和庄对赌，是和散户对赌
  • 返奖率 65%，房费 35%（高于普通博彩）
  • 任何"知识缺乏的盲注策略"长期 ROI ≈ −35%。不可能靠运气或感觉盈利
  • 唯一可行 edge：散户群体定价错误 vs 国际市场。文献显示 5–10pp 量级，需用 35% 房费 cover 后才有正期望
警告 2：真正 Go/No-Go 决策推迟 ~6 个月
  • 历史回测最多告诉我们"模型预测多准 vs 平均欧赔"
  • 历史回测不能告诉我们"北单散户偏差是否真存在 + 大到能 cover 35% 房费"
  • 必须 Live Collector 跑 3+ 月 + 200+ 注 forward test 才有统计意义
  • 在此之前任何投入都是探索性投入，不能靠它盈利
警告 3：合规
中国大陆体育彩票为国家专营。本系统仅用于个人决策辅助，不做代购、不托管、不收费咨询。生成的投注清单只在本地保留。
