# 策略诊断

先阅读 [诊断方法学](references/methodology.md)。它记录用户经过多轮研究确定的诊断框架；让平只是概率层的一个例子，不能把所有问题都变成让平校正。
按当前症状查 [函数与数据契约索引](references/functions.md)，再读对应 R 源码和测试。实现保留在仓库 `r/`，不要把业务代码复制进 skill，或另写相同的结算/时序逻辑。

定位当前 beijing-lot 仓库根目录，读取其 AGENTS.md 和实时 Issue Graph；方法文档和过往结论不能覆盖当前图、用户范围或参数。普通诊断不自动创建目标、改状态、发评论、重训、部署或开始新的采集。已有明确授权的提交/推送按会话执行。

## 执行

- 明确本轮问题、比较单位、数据/模型版本、时间范围和冻结参数。先核对已发布输入和结算边界；数据存储操作使用仓库的数据存储技能。不要按目录年龄选择版本。
- 从收益恒等式定位症状，再沿数据、概率、候选池、选组、深度/广度、结算逐层检验；只做能区分当前假设的检查，不要求每次跑完所有模块。
- 每个假设写出可否定它的结果，安排局部受控对照和必要的完整流程对照。固定比较范围与预算；区分单场、组、期三个层级。
- 时间分段和分层必须给出支持数。区分样本构成变化、同类关系变化和随机波动；最大回撤区间属于事后窗口。相关性使用逐期净收益，不用累计曲线证明分散化。
- 历史诊断输出不直接变成决策接口。凡是要拟合、调参、选门槛/种子/权重、切换策略或优化资金，必须另走 AGENTS.md 规定的 `src/temporal_learning` 截止时间、历史准入、冻结凭据和独立重放流程。skill 不提供规避入口。
- 使用 R 和 QMD；新业务函数落在 `r/` 并配 `testthat`，Python 只用于适当的输入/存储适配且落在 `src/`。函数路径、输入快照、参数、代码身份、测试及渲染证据随交付记录。
- 图直接发到会话。给出诊断矩阵和明确结论：已支持、已否定、证据不足；不以一串新研究建议代替结论。后续动作只保留能改变判断的最小实验。

## 常驻约束

Titan 为基本面主源，Nowscore 用于核对补缺；复用另一会话已清洗验收数据。赛前估算 SP 来自欧赔与大小球映射，实际北单 SP 只用于结算；原始估算与实际价格不同不是数据错误。比分保护默认关闭，除非本轮明确纳入。既定专家版本由独立任务维护，本 skill 不擅自重训。

业务参数显式传入；7串1、2元票、1024元预算、10万元本金和0.65系数是既往具体研究设定，不能隐含写死到所有新实验。0.65 若已在票级回款中应用，汇总不得再次应用。无投注、待结算、数据不可用、停投和实际亏损分别处理。

源码维护位置为 `skills/beijing-lot-strategy-diagnostics/`；用户目录中的安装副本与整个 skill 目录同步。详细方法学的唯一仓库维护源是下方 reference，不另维护一份容易漂移的全文副本。
