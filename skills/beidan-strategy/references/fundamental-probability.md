# 基本面战力概率（FM-1.7.1）

1. 绑定场次、比赛类型、完整目标期ID及显式决策截止（默认T−24h），来源代理仅用于历史诊断。
2. 原生λ先以目标赛事competition_id、场地及显式截止选择同赛事历史，再同时考虑长期主客场与近期状态。复用共享截止准入和现有 `FitOpponentGoals()` 输出的 `same_support_raw`；不采用其对手归一化 `parameters`。赛事身份不明、同赛事支持不足必须列缺口，不跨赛事补足。默认近期alpha=0.5；同场地最近8场与同场地完整历史进失球经验分布分别归一化，再按(1-alpha)*long+alpha*recent混合，交叉均值生成主客λ。完整历史含近期样本，显式披露。最小实现`estimate_recent_venue_goals()`：主队主场、客队客场，至少12场历史及8场近期，ESS>=8，α不得从已知目标结果择优。主场/客场近期与全场地近期分别展示，不能混用。
3. 有对手强度、联赛环境、阵容/伤停等信息时评估是否进入原生估计；目前最小函数尚未量化这些项，缺失要明示，不伪造调整。有依据改变α时保存新政策、理由、收据并重建，不能只改字段。历史权重、ESS、截止、分区及重放统一使用共享temporal_learning。ρ显式固定−0.1作为专家起点，未校准。
4. 同截止欧赔、大小球、亚盘联合反解市场λ及完整DC，保存残差；按[置信审查与来源切换](confidence-market-switch.md)冻结审查。基本面低置信或未确定，且市场证据充分、一致时，直接选择市场网格；不再固定混入30%原生。市场缺通道、过旧或矛盾时不切换；部分欧赔篮子必须披露，并在截止前明确充分性裁决，不能冒充完整覆盖。基本面有明确反对市场的事实则保留原生。
5. 冻结选中的尾部前网格。按[累计90%核心](scenario-tail-adjustment.md)构造完整分档目标：降序累计严格超过90%，边界并列整组纳入，外围0.3；这是固定专家政策。北单线不能确定来源或核心。
6. `adjust_score_margin_distribution()`直接重加权比分，不返拟合λ/ρ；随后`project_score_outcomes()`投影实际北单线，完整类别排序Top1/Top2/Top3。净胜球单档不替代类别排名，保护不固定平局。
7. 保存原生、市场对照、接受调整、尾部前后网格、α/近期日期/组件及权重、排名/累计/边界并列/核心质量、概率差距和敏感性；绑定输入/政策/传递代码哈希、截止及共享收据，再追加标签。已知结果的讨论不是独立回测。

`EstimateFundamentalIssue()`目前仍是旧历史底座阶段，FM14有界客户端是冻结对照；不能直接标FM15。当前FM17复用FM16原生/市场来源选择，并使用累计90%核心目标构造；JEV/定性可靠性账本由调用侧供给，尚无自动数值置信评分或新整期效果验证。FM15已完成26098、26101、26102历史诊断，不能重新标为FM17。详见[函数边界](fundamental-workflow.md)和[报告契约](prediction-report.md)。
