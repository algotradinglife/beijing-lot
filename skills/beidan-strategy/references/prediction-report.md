# 基本面战力预测报告

当前完整流程版本 **FM-1.7.1**（同赛事原生取样，见[版本说明](same-competition-release.md)），以[方向与比分校正](direction-score-adjustment.md)为最终阶段；比赛类型和近期对手强度继续按[专项证据契约](competition-strength-market.md)审查。

用户要求“预测报告”“战力概率”“让球胜平负和比分概率”时使用。输出可读 HTML、可执行 QMD 与概率/证据 CSV。单场报告不需要预算，批次每场保留独立证据与参数。生成报告不自动生成票单、发布远程网页或开启更新服务。

## 报告开头：身份与预测结论

明确期号、编号、双方、主客、联赛/赛制、开球时区、决策截止、北单有符号让球 h、来源身份和报告用途。第一屏给Top1主选、Top2保护、主要失手路径、最终让胜/让平/让负概率、主要比分及其概率、基础/市场阶段λ主/λ客/ρ、主要支持因素与分歧。最终专家网格不伪造新的λ/ρ。概率以百分比呈现，CSV 为0–1；模型比分是分布，不将最高概率比分写成确定赛果。

报告用途必须与证据匹配：实际赛前可用性得到证明才标为前瞻预测；历史重放、历史代理诊断、看过赛果的事后复盘分别标识。当前 fundamental_probability 快照适配仅授权历史诊断；本技能新增的是报告契约，不代表已实现生产前瞻接口。准入不满足时明确缺口，不切换声明伪造合法预测。合法接口不可用时仅提供已授权的诊断报告或数据缺口，不给出冒充冻结赛前决策的产物。

## 各维度证据与综合判断

按信息覆盖逐项分析以下维度，不机械重复同一事实：

| 维度 | 要回答的问题 |
|---|---|
| 联赛与赛制 | 比赛性质、强弱背景、进球/平局统计及支持量，是否跨级或中立场 |
| 长期战力与主客 | 赛季主客进失球、样本量、对手构成及初始λ来源 |
| 近期状态 | 最近成绩、攻防趋势、对手强弱，与长期样本是否重叠 |
| 阵容与伤停 | 已确认首发/名单、缺席位置与影响；预期阵容和确认阵容分开 |
| 战意 | 升降级、排名、轮换等事实，如何影响进攻投入、防守或节奏 |
| 历史交战 | 时间、场地、人员可比性、样本量及是否已计入统计 |
| 赛程与体能 | 休息、密度、旅行及轮换证据 |
| 战术与环境 | 对位机制、风格、天气/场地；未知不得补造 |
| 盘口及变化 | 欧赔、北单、大小球及可用让球盘的水平、走势、报价年龄和分歧 |

每项记录事实/假设、来源与时间、可用性证据、可靠性、影响方向、是否用于调整，以及不采用的理由。来源优先复用验收快照；Titan 主源、Nowscore 核对补缺，V球按实际覆盖使用。无平台 xG 不把比分推算λ称为平台 xG。分析结尾综合哪些信息支持主/客、哪些支持平局与低/高总进球；展示矛盾与限制，不仅罗列资料。

## 盘口轨迹

只使用截止前报价。欧赔每公司倒数归一化，再对同一时点可用公司取平均；同时展示原始平均赔率、公司数和篮子变化。时间对齐使用此前最后有效报价，披露报价年龄、缺失和是否为固定公司篮子，不插值未来报价。不把盘口变化直接解释为资金流或内幕。

北单相对定价按 SP 倒数归一化，和欧赔普通胜平负同口径时才直接对照；北单有让球时分图或分栏明确结果空间。0.65不用于概率归一化。变化曲线 y 轴使用概率、x 轴注明时区；原始 SP 另表保留。只有一个快照时呈现水平，标明无法判断走势。

大小球展示盘口线、水位/十进制价格及时间；盘口线改变时不能把不同阈值的“大球概率”直接连成可比趋势。可在支持的盘口与结算模型下转换为总λ参考；不支持的盘口保留原始轨迹并说明未用于反解。亚洲让球盘与北单固定整数让球不同，不能混用结算类别。盘口先独立反解；定性可靠性审查触发来源切换，低置信且市场充分一致时直接采用市场网格，其余保留原生。不能以分歧本身判低置信或重复加成同一信息。

## 参数与概率产物

保留数据基准、市场复核、方向校正三份视图；原FM-1.2输出可作历史对照。每个净胜球档记录旧质量、目标质量、倍率、证据、理由及是否人工。公平让球线只作诊断，不自动改变北单固定让球。

原生λ由长期/近期状态共同生成，市场DC先独立保存，再依据[可靠性裁决](confidence-market-switch.md)直接选用或拒绝；不做固定30%混合。最终调用`adjust_score_margin_distribution()`生成同一比分网格，再按i-j+h的符号汇总北单三类。先冻结概率降序累计90%核心、跨界及边界并列档、前后质量与归一化Z，外围0.3；不使用单双中心或半径限制；明确的独立定性retain审查保留。最终冻结后才`project_score_outcomes()`投影实际h，输出Top1/Top2/Top3、差距、并列及边界敏感性。展示alpha=0.5的来源、完整与近期组件、样本/日期/ESS和缺失的对手评级/阵容；完整比分与市场信息未完成时不能冒充完整报告。

输出完整比分网格 CSV（fixture_id/stage/scenario/home_goals/away_goals/probability），正文展示按概率排序的前若干比分、累计质量及剩余质量，数量或覆盖目标作为显式报告参数；同时用比分热图展示主要区域。公布网格范围、截断尾部及归一化口径，比分聚合须与报告三分类一致。h=0可合并展示普通与让球结果，避免重复。

检查概率非负、和为1（声明截断口径）、ρ可行性、比分聚合与普通/让球结果一致。展示有限且显式的λ/ρ敏感性情景，不伪造未经估计的置信区间；情景上下界不等于统计置信区间。平局判断结合总λ、λ差、定性及市场，联赛平局率仅作背景，不直接叠加。

## 冻结与验收

冻结输入身份/来源哈希、截止、证据及调整账本、参数、三份概率视图、完整比分网格与代码身份；实际赛果在冻结后单独接入。回测使用同场次同口径比较三阶段，事后人工判断不能充当独立赛前预测。

QMD调用受测实现，声明依赖与复现命令；函数测试、干净进程渲染、截止治理核验与 codex review 按仓库要求完成。报告需检查关键表、概率曲线和比分热图的标签、单位与缺失；无历史盘口则记录缺失，不编造曲线。此契约不新增算法，实际实现缺口先披露并按本轮授权补齐，不能仅凭文档宣称计算能力已交付。
