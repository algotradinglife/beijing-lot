2. 核心数学

2.1 北单串关 break-even

奖金 = ∏SP_i × stake × 0.65   （0.65 只乘一次！rake 不论关数仅收一次）

每腿需 q = p × SP ≥ (1/0.65)^(1/N) = 1.538^(1/N)
  N=1: 1.538 (单关不可能 — 53.8% edge)
  N=4: 1.144 (现实可达，OOS 实测 niches q ≈ 1.4)
  N=7: 1.064 (理论可达但变量摧毁)

5. 风险诚实声明

⚠ 单年回报极不稳定

8 年里：6 年正收益，3 年负收益。最佳 2019 年 +643%；最差 2026 起跌 −40%。

OOS 测试期（2022-2026）单年中位数 CAGR 仅 +1%。亮眼的 261% 8 年 CAGR 是少数大年驱动，不是稳定线性增长。

⚠ 数学 vs 心理学

−37% Max DD 看似数字小，实际意味着账户从 200k 跌到 126k，连续 45 周回不到峰值。这是 strategy 本质特征（rare-hit + 反弹驱动），不可消除。

ProfitLock 的真实价值：把"盈利已经实现"和"还在风险中"分离。心理上更可承受。

⚠ Kill criteria（必须设）
  1. 累计 ≥ 50 注后 ROI < −25%
  2. 单批次 DD > −50%
  3. 活跃 bankroll 跌至初始 50%
  4. Niche q 跨季度回退（持续 ≥ 2 季度 q < 1.10）

触发任一 → 暂停下注，复盘 2 周，再决定继续/退出。

6. 实战 Pipeline（已就绪）

Phase 5a 操作流程
每周操作：
  1. python -m src.phase5a plan --bankroll <current> --window-days 7
     → 输出可买票清单（场次、选项、stake、票数）
  2. 用户线下买票（北单网点，京津粤）
  3. 比赛结束 → python -m src.phase5a reconcile --week YYYY-WW
     → 自动对账 + 累计 PnL 入 CSV
  4. 若 bankroll 达到 high-water-mark × 2 → 提 30% 到锁定账户
  5. 触发 kill criteria → 暂停
